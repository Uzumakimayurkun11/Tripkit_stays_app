# 🌍 TripKit - Travel Booking & Itinerary Planner App

> A modern, warm mobile application experience designed to streamline trip planning, stay discovery, and host reservation management.

[View Live Prototype](https://uzumakimayurkun11.github.io/Tripkit_stays_app/) • [Figma Design File](https://www.figma.com)

---

## 🎨 Project Overview
**TripKit** is a two-sided stays marketplace prototype built to bridge the gap between guests looking for unique accommodations and hosts managing their property listings. The goal of this design system was to reduce cognitive load during trip planning through a warm, intuitive interface, clean card layouts, and clear information hierarchy.

* **Domain:** Travel, Hospitality, & UI/UX Design
* **Primary Tools:** Figma, Webflow, HTML/CSS/JavaScript
* **Scope:** End-to-end guest journey (Discovery → Booking → Itinerary) and host management workflow.

## ✨ Key UX Features & Architecture

### 1. Seamless Guest Experience
* **Guided Discovery:** Curated stay collections and intuitive filter systems allow users to quickly browse accommodations by preference.
* **Frictionless Booking Flow:** Streamlined date selection, guest counts, and clear cost breakdowns to minimize drop-off.
* **Interactive Itinerary Planner:** Day-by-day trip structuring keeping activities, bookings, and reservations organized in one hub.

### 2. Dedicated Host Mode
* **Property & Listing Management:** Toggle easily into a host interface to review active listings, pricing, and availability calendars.
* **Earnings & Analytics:** Transparent tracking of revenue payouts, occupancy rates, and upcoming reservation requests.
