# TripKit

TripKit is an interactive mobile prototype for a two-sided stays marketplace. It follows the guest and host flows in the [TripKit Figma file](https://www.figma.com/design/068XarewcMxPw1bP8Hrmhv/TripKit?node-id=0-1).

## What to explore

- Browse and filter stays, save favorites, and view property details
- Choose dates and guests, complete a booking, and view the trip itinerary
- Switch into host mode to review listings, reservations, and availability
- Open the inbox and send a sample message

This front-end prototype uses sample data and stores saved places in browser local storage. It does not process payments or create real bookings.

## Live preview

The GitHub Pages deployment workflow publishes the site when changes are pushed to `main`.
