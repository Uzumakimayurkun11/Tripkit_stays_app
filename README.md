# TripKit — Stays that feel like yours

TripKit is a warm stays marketplace concept for guests and hosts. Explore properties, plan a trip, save favorites, manage bookings, and handle host listings through a thoughtful mobile experience.

**[Open the live preview](https://uzumakimayurkun11.github.io/Tripkit_stays_app/)** · [View the GitHub repository](https://github.com/Uzumakimayurkun11/Tripkit_stays_app)

## Explore the experience

- An interactive mobile prototype for browsing, filtering, and booking stays
- A screen browser with all 24 guest and host design screens
- Searchable screen navigation, previous and next controls, and full-size previews
- A warm visual style with soft neutrals and coral accents

## Built with

HTML, CSS, and JavaScript, with original screen exports and interface assets.
